# Attractor Builder

Программа для построения фрактальных аттракторов на основе системы итерируемых функций (IFS). Приложение считывает аффинные коэффициенты из файлов и генерирует изображения с настраиваемым уровнем детализации и чёткости.

[![Build CI](https://github.com/hospitaler17/attractors/actions/workflows/make_main.yml/badge.svg)](https://github.com/hospitaler17/attractors/actions/workflows/make_main.yml)

## 📋 Описание

Attractor Builder — это графическое приложение на C++ с использованием фреймворка Qt, предназначенное для визуализации фрактальных аттракторов. Программа реализует алгоритм DSIF (Discrete Space Iterated Functions) для построения фрактальных изображений.

### Возможности

- 📊 Построение фрактальных аттракторов различной сложности
- 🎨 Настройка цветов фона и пикселей
- 🔍 Различные уровни приближения и детализации
- 💾 Загрузка аффинных коэффициентов из файлов
- ⚙️ Гибкие настройки отображения
- 🌐 Поддержка русского языка

## 🛠 Требования

- **Qt**: версия 6.2 или выше
- **Компилятор**: g++ с поддержкой C++11 или MSVC
- **ОС**: Linux (Ubuntu), Windows

### Формат файлов коэффициентов

Файлы коэффициентов (`.coef`) содержат аффинные преобразования в формате:

```
a b c d e f
```

Где каждая строка представляет одно аффинное преобразование:
- `a, b, c, d` — матрица преобразования 2×2
- `e, f` — вектор смещения

**Пример** (файл `crystal.coef`):
```
0.2550 0.0000 0.0000 0.2550 0.3726 0.6714
0.2550 0.0000 0.0000 0.2550 0.1146 0.2232
0.2550 0.0000 0.0000 0.2550 0.6306 0.2232
0.3700 -0.6420 0.6420 0.3700 0.6356 -0.0061
```

### Примеры коэффициентов

В директории `coefs/` представлены готовые файлы для построения различных фракталов:

- `Koch.coef` — кривая Коха
- `crystal.coef` — кристаллическая структура
- `ddragon.coef` — дракон Хартера-Хейтуэя
- `koverB.coef` — ковёр
- `parallel.coef` — параллельные структуры
- `tree.coef` — фрактальное дерево

## ⚙️ Настройки

Приложение хранит настройки в файле `settings.ini`:

- **background** — цвет фона (RGB)
- **pixelColor** — цвет пикселей аттрактора (RGB)
- **lastWorkSettings** — последние параметры работы:
  - Прозрачность фона
  - Путь к последнему файлу коэффициентов
  - Размер окна и интервалы отображения
  - Выбранный метод построения
